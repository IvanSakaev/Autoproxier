# AutoProxy

AutoProxy проверяет прокси и VPN-профили, выбирает самый быстрый по скачиванию
и публикует его как SOCKS5 на `127.0.0.1:1080`. Адрес сохраняется при
переключении. Программа запускается от обычного пользователя и не меняет
настройки KDE, DNS системы или маршруты.

## Запуск на Manjaro

Понадобятся Python 3.11+, curl 8.4+ и ядра для ваших форматов. Добавьте
[Xray](https://github.com/XTLS/Xray-core/releases) для клиентских JSON и
[Mihomo 1.19.34+](https://github.com/MetaCubeX/mihomo/releases) для подписок,
WireGuard и AmneziaWG. Положите исполняемые файлы в `PATH` либо укажите их
полные пути в полях `xray`, `mihomo` и `curl` в конфигурации.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp autoproxy.example.json autoproxy.json
chmod 600 autoproxy.json
```

В `autoproxy.json` замените примеры в `profiles` и `subscriptions` на
свои значения. Оставьте пустой список для источника, который не используете.
Относительные пути профилей считаются от папки с конфигурацией.

```sh
.venv/bin/python -m autoproxy --config autoproxy.json
```

Укажите в приложении SOCKS5 `127.0.0.1:1080`. Если приложение принимает URI,
используйте `socks5h://127.0.0.1:1080`, чтобы передавать доменные имена прокси.

```sh
curl --noproxy "" --proxy socks5h://127.0.0.1:1080 https://www.cloudflare.com/cdn-cgi/trace
```

Остановить демон можно через `Ctrl+C` или `SIGTERM`.

### Установка из релиза

Скачайте wheel `autoproxy-0.1.0-py3-none-any.whl` и установите его в отдельное
виртуальное окружение. Зависимость PyYAML устанавливается через pip. Ядра
Xray и Mihomo и утилита curl устанавливаются отдельно, как описано выше.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install ./autoproxy-0.1.0-py3-none-any.whl
cp .venv/share/autoproxy/autoproxy.example.json autoproxy.json
chmod 600 autoproxy.json
```

Укажите свои профили и подписки в `autoproxy.json`, затем запустите
`.venv/bin/autoproxy --config autoproxy.json`.

## Форматы

- Клиентские Xray JSON содержат самостоятельные выходы VLESS, VMess, Trojan,
  Shadowsocks, SOCKS, HTTP или Hysteria. Из массива `outbounds` проверяются
  отдельные серверы. Цепочки выходов и маршрутизация из входного файла не
  применяются.
- WireGuard и AmneziaWG используют `.conf` с одним `[Interface]` и одним
  `[Peer]`. Ключи, адреса, DNS и параметры обфускации переносятся в
  конфигурацию Mihomo. Хуки вроде `PostUp` не исполняются. Профили с
  одной парой клиентского и серверного ключей не запускаются одновременно.
- HTTP(S)-подписка может содержать обычный или Base64-список URI (VLESS,
  VMess, Trojan, Shadowsocks, Hysteria2 и SOCKS), либо Clash/Mihomo YAML
  с верхнеуровневым списком `proxies`. Проверяется каждый уникальный узел.
  Последний успешно разобранный список каждой подписки хранится в памяти
  на случай временной ошибки загрузки.

## Как выбирается узел

Для TCP-профиля сначала проверяется порт сервера. Затем проверяется TCP через
туннель и делается короткий HTTPS-запрос. Для туннеля с UDP-транспортом проверка
начинается с TCP через сам туннель. Все прошедшие профили по очереди скачивают
до `download_bytes` за `download_timeout`. Стандартный объём — 16 МиБ на
профиль за один полный обход. Например, 100 рабочих узлов могут израсходовать
до 1,6 ГиБ. URL по умолчанию использует `{bytes}` для запроса нужного объёма.
Если указать собственный URL, он должен отдавать файл размером до
`download_bytes` либо поток, который curl сможет прервать на этом лимите.

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `scan_interval` | 1800 с | Пауза между полными обходами |
| `health_interval` | 5 с | Пауза между проверками активного узла |
| `health_failures` | 2 | Число последовательных ошибок для смены узла |
| `retry_interval` | 15 с | Пауза перед новым обходом, когда узлов нет |
| `drain_timeout` | 120 с | Сколько открытые соединения могут жить после смены узла |
| `concurrency` | 8 | Максимум одновременных быстрых проверок |
| `check_urls` | Google и Cloudflare | HTTPS-адреса проверок. Достаточно одного успешного ответа |

После сбоя демон перепроверяет резервный узел перед переключением и повторяет
полный обход. Новые TCP-соединения идут через новый узел, а открытые дочитывают
данные через прежний до закрытия или истечения `drain_timeout`. Если прежний
туннель оборвался, приложение должно заново открыть потерянные соединения.
Локальный SOCKS5 поддерживает TCP `CONNECT`, включая IPv4, IPv6 и домены.

## Сборка и тесты

`python -m build` собирает исходный архив и wheel в `dist/`. Команда требует
установленный пакет `build`.

```sh
.venv/bin/python -m unittest discover -s tests -v
```

Тесты переключения используют локальные TCP-сокеты. Для интеграционного
теста HTTPS также нужны curl и openssl. Если задать `AUTOPROXY_CORE_DIR`
с каталогом, содержащим `xray` и `mihomo`, тесты запустят локальный
VLESS-стенд и проверят загрузку конфигурации AmneziaWG.
